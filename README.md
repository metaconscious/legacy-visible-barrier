# Legacy Visible Barrier

Legacy Visible Barrier is an Ornithe (Feather) client mod for Minecraft 1.8.9.

When toggled, this mod allows you to see barriers the same way you see any other block.

Use the default key bind `B`, or change it under Controls.

## Requirements

- Ornithe/Feather loader for Minecraft 1.8.9 (built with loader 0.18.1)
- Ornithe Standard Library (OSL) for 1.8.9 (built against 0.16.3 keybind/lifecycle modules)

## Notes

- Legacy Fabric API/loader builds are still supported in `legacy-fabric` branch; install this build on Ornithe with OSL.
